# Iteración 05 - Construcción incremental del módulo

## Objetivo

Empezar la `Entrega 4` con implementación real del módulo, pruebas automatizadas y una estrategia clara de despliegue o ejecución demostrable.

## Entrega asociada

- esta iteración forma parte de la `Entrega 4`.
- no cierra una entrega formal por sí sola.

## Entregables esperados

- `docs/arquitectura/c4-componentes.md`
- código backend ejecutable en `src/main/java/`
- pruebas unitarias y de aceptación mínimas
- al menos un `.feature` vivo no template
- primer corte de despliegue, ejecución o estrategia de demo técnica
- `docs/arquitectura/diagrama-codigo.md` si hace falta para explicar complejidad real

## Criterio de cierre

- el módulo deja de ser sólo diseño y pasa a ser una solución ejecutable;
- existe una primera vertical implementada con cobertura automatizada;
- la arquitectura de componentes conversa con el código real;
- el equipo puede mostrar cómo correr, probar o desplegar su módulo.
