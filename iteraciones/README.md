# Iteraciones

Los enunciados del TPG viven en esta carpeta.

La operatoria general es:

- trabajar siempre sobre la rama de la iteración correspondiente;
- abrir el PR `iteracion-0X -> main` con título `iteracion-0X`;
- mantener actualizados los artefactos vivos del módulo;
- usar `entregas/iteracion-0X.md` sólo como bitácora interna opcional si al squad le resulta útil;
- cerrar las entregas formales con los manifiestos `entregas/entrega-0X.md`.

## Mapa iteración -> entrega

- `iteracion-01` alimenta `entregas/entrega-01.md`.
- `iteracion-02` es parte de `entregas/entrega-02.md`.
- `iteracion-03` cierra `entregas/entrega-02.md`.
- `iteracion-04` alimenta `entregas/entrega-03.md`.
- `iteracion-05` es parte de `entregas/entrega-04.md`.
- `iteracion-06` cierra `entregas/entrega-04.md`.
